# Tembo Homebrew tap

```sh
brew install tembo/tap/tembo
```

Installs the [Tembo](https://www.tembo.io) CLI on macOS and Linux (arm64 and x64).
Without Homebrew, use `curl -fsSL https://cli.tembo.sh | sh`.

`Formula/tembo.rb` is updated automatically on every CLI release by
`.github/workflows/release-cli.yaml` in tembo/monorepo. Don't edit it by hand.
